# Changelog v1.1.0

## New Features
- **Visual Refresh**: Updated application primary theme to Blue.
- **App Icon**: Added new application icon.
- **Port Forwarding**:
    - **Auto-Restart**: Successfully implemented logic to automatically restart port forwarding sessions if the `kubectl` process disconnects or crashes (waits 3s before retry).
    - **Duration Tracking**: Added a `Duration` column to the "Services" tab to show uptime of forwarded ports.
    - **Robust Exclusion**: Fixed exclusion logic to be port-specific (e.g. `namespace/service:port`) to avoid excluding all ports of a service.
    - **Status**: Simplified status display (Forwarding, Stopped, Failed).
- **Pod Monitoring**:
    - **Custom Refresh**: Replaced the numeric input with a clean `[-] [Value] [+]` control for refresh interval.
    - **Stability**: Wrapped the Pod Watcher in a keep-alive loop to prevent the "stopped refreshing" issue during long sessions.
- **Portable Publishing**: Added `publish-portable.ps1` script to easily generate a single-file executable.

## Fixes
- **Scrolling**: Fixed "jumping" layout issues in Service List by strictly constraining the height of interactive cells (CheckBox, ToggleSwitch).
- **Build**: Resolved property errors related to DataGrid virtualization.
