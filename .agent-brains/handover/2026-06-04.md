### Decisions Made
- `.deb` only (no AppImage/rpm/tar.gz); self-contained; linux-x64 only. Hand-rolled `dpkg-deb` instead of Velopack's Linux path to keep the Windows flow untouched.
- GitHub Pages + GPG self-hosted apt repo over packagecloud/Cloudsmith — zero-cost, no third-party dep.
- `vars.*` gate instead of `secrets.*` gate (forced by GHA — `secrets.*` is not allowed in `if:` expressions).
- No `Program.cs` or `KubeTools4Dev.csproj` changes — the cross-platform paths and `WinExe` publish were verified to already work on Linux during the smoke test.
- No ADR written — these are packaging/CI-shape decisions, not architectural choices about the app itself. Captured in the plan + maintainer guide + commit messages.
